# 让桌上的猫替你盯 AI 干活——bongocat-mcp 使用指南

> 你在用 AI 编程助手写代码，它跑任务的时候你在摸鱼。任务跑完了？有个按钮要你批准？出错了？
> 别盯着终端了——**桌上的猫会告诉你**。
>
> 项目地址：[bongocat-mcp](https://github.com/emicyx/bongocat-mcp)

## 这是什么

[bongocat-mcp](https://github.com/emicyx/bongocat-mcp) 把桌面宠物猫（各类 BongoCat）变成了 AI 助手的"任务播报员"：

- AI 完成任务 → 猫头顶弹出气泡"✅ 任务完成啦，快来看看喵～"，眼睛变成星星眼
- AI 等你审批 → 气泡提示"❓ 等待你的审批"，猫一脸疑问地看着你
- 工具执行出错 → 猫委屈地哭给你看

气泡几秒后自动消失，表情过一会儿自动切回默认——猫播报完就恢复日常，不会一直顶着星星眼碍事。

目前支持三种主流的猫，装好即用：

| 猫的版本 | 说明 |
|---|---|
| BongoCatMver 皮肤版 | 常见的 C++ 改图皮肤版，全自动接入（见下文） |
| BongoCat 官方/重打包版 | Tauri 桌面版，首次接管会自动重启一次猫 |
| 自编译版 | 带内置控制通道的版本 |

## 已实现的功能

### AI 可以直接操控猫

项目把猫的所有动作封装成了 14 个标准工具（AI 圈通用的 MCP 接口），AI 助手可以按需调用：让猫打字、敲键盘、做动作、切换表情、弹气泡、显示/隐藏猫窗口……凡是猫会做的，AI 都能让它做。

### 事件播报插件（ZCode 版已就绪）

这是核心玩法。装上配套插件后，AI 助手的五个关键时机会自动触发猫的播报：

| 时机 | 猫的反应 |
|---|---|
| 会话启动 | 打招呼："已就位，随时开工喵！" |
| 你提交新任务 | "收到，开始干活！" |
| **任务完成** | 气泡播报结果 + 星星眼 |
| **等待你的审批** | 气泡显示是哪个操作在等确认 + 疑问脸 |
| 工具执行出错 | 委屈哭泣 |

### 网页仪表盘

本地起一个控制台（浏览器打开），可以看到：猫的连接状态和能力清单、全部配置项的可视化编辑、以及一个"试玩台"——在网页上点按钮就能让猫切表情、打字、冒气泡，还有最近 200 条操作流水可查。

### 换皮肤不用改代码

不同皮肤的猫表情差别很大，有的甚至没做表情。插件的做法是每次播报时实时读取当前猫的表情列表，按名字找合适的目标（比如任务完成优先找"星星眼/点赞"这类）。所以：

- 换一套皮肤，猫自动适配新表情
- 皮肤没做表情 → 自动降级为只弹气泡，不报错不折腾

## 怎么用：从零到猫开工

### 第一步：准备（一次性）

```bash
git clone https://github.com/emicyx/bongocat-mcp
cd bongocat-mcp
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

然后把示例配置复制为正式配置：`copy config.example.json config.json`。

### 第二步：启动仪表盘

```bash
python dashboard.py
```

浏览器会自动打开仪表盘页面，保持它后台运行即可（这就是猫的"控制中枢"，日常只需要这一个命令）。

### 第三步：接入你的猫

**Mver 皮肤版**：如果猫正在运行但还没开网络同步，在仪表盘点「🚀 一键接入 Mver 新猫」——它会自动定位猫、打开猫的网络开关、重启猫并接管，全程无需手动改配置。

> [!TIP]
> 一键接入会文本级改写猫的 `config.json` 来开启网络同步（接收模式），不改程序本体；新装的皮肤版默认不监听 UDP，点一下即可修复。

**其他版本**：在仪表盘的"配置编辑"里填一下猫的程序路径，或直接用自带的自动探测。

接入成功后，仪表盘的状态页会显示当前猫、它支持哪些能力、表情和动作列表。

### 第四步：安装 ZCode 插件

1. 打开 ZCode → 设置 → 插件管理 → 发现 → 点 `+` 添加市场
2. 选择本地目录：`bongocat-mcp/zcode-plugin`
3. 安装列表里的 **bongocat-notify**（新插件默认启用）

### 第五步：验证

新开一个 ZCode 会话，输入 `/bongo-test`——AI 会自动走一遍完整链路：确认猫在线、列出表情、现场切换两个表情、弹出测试气泡。猫表演成功，就是全通了。

之后什么都不用做：正常给 AI 派活，每次任务完成、等待审批、出错时，猫都会自动播报。

### 想调整播报行为？

在插件目录放一个 `bongocat-notify.json`（或放在 `~/.zcode/` 下），只写想改的项：

```json
{
  "expressionDuration": 20,
  "events": {
    "user-prompt": { "enabled": false },
    "stop": { "text": "🎉 搞定！{tool}", "expressions": ["点赞"] }
  }
}
```

上面这份配置的意思：表情保持 20 秒再回默认；每次提交任务不播报（太吵）；任务完成的文案换成"🎉 搞定！"，表情优先用"点赞"。`{tool}` 会自动替换成具体的工具名。

## 几个使用提示

- **仪表盘保持运行**：猫的播报都经过它；它没开时猫安静如鸡，但不影响 AI 正常干活

> [!NOTE]
> 插件 hook 走仪表盘的 HTTP 接口，仪表盘没开时播报会静默跳过并记入日志，绝不阻塞 ZCode 会话。

- **Mver 猫接入后，键鼠跟随由接管程序负责**：这是接收模式的正常机制，仪表盘会把你的真实键鼠转发给猫，体验和原来一样

> [!CAUTION]
> 同一时间保持一个接管程序在跑就好；重复接管会让表情切换变得不稳定，也只有一个 Mver 实例能占用接收端口。

## 后续方向

- **QQ / 聊天机器人接入**：AstrBot 侧的接入方案已经论证完成——收到 QQ 消息时猫冒气泡转述，让猫从"编程助手播报员"扩展成"消息播报员"，技术上复用同一条链路，实现文档已在仓库中
- **接入更多 AI 客户端**：插件开发指南（仓库 `docs/zcode-plugin-dev.md`）已把接入方式、配置模板和避坑清单整理成文档，其他客户端照着做半天即可接入
- **播报更智能**：比如按任务时长/重要程度调整气泡停留时间、播报节奏，让猫的表现更有"情绪"
- **表情语义库**：沉淀更多皮肤的表情命名规律，让开箱即用的匹配覆盖率更高

## 结语

把猫挂上 AI 之后，摸鱼的时候终于不用时刻盯着终端了：任务跑完、需要你点头、出了岔子，猫都会第一时间告诉你。整套东西没有重编译、没有改猫本体，就是一层"播报员"的壳，接上就能用。
